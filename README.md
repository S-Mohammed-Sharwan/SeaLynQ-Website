# SeaLynQ website

This is a standalone, responsive product showcase. It uses plain HTML, CSS, and JavaScript; the hero scene uses Three.js from jsDelivr and the typefaces load from Google Fonts.

## Run locally

Serve this folder over HTTP, then open the local address in a browser. For example:

```powershell
py -m http.server 8000
```

Open `http://localhost:8000`. An internet connection is needed for the Three.js module and web fonts. Without WebGL, the hero keeps its CSS ocean fallback.

The network visualization and app screens are illustrative demos. They do not connect to live SeaLynQ devices or represent a deployed safety service.
